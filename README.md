# EWF Learn — Landing Page Edukasi

Frontend statis responsif untuk edukasi awal tentang Gold, Hang Seng/HKK, dan Nikkei/JPK.

## Cara menjalankan
- Buka `index.html` di browser, atau gunakan Live Server.
- Tidak membutuhkan Node.js, backend, database, API key, maupun build step.

## Deploy ke Vercel
1. Upload folder ini ke repository GitHub.
2. Di Vercel, pilih **Add New Project** lalu import repository.
3. Framework Preset: **Other**.
4. Build Command: kosongkan / Override off.
5. Output Directory: `.` (root).
6. Deploy.

## Catatan data
Grafik harga dan candle adalah **simulasi ilustratif lokal**, bukan data bursa real-time. Informasi produk adalah pengantar edukasi; cek spesifikasi, jam perdagangan, biaya, margin, legalitas dan ketentuan terbaru pada kanal resmi EWF/regulator. Halaman ini bukan rekomendasi transaksi.
